## Qoidalar
1. **Har bo‘lim o‘z lug‘at faylida**: `export const X_DICT: Record<Locale, XDict> = { uz, ru, en }` — `uz` obyekti turni belgilaydi (`type XDict = typeof uz`), `ru`/`en` shu turga majbur (TypeScript bo‘sh kalitni ushlaydi). Funksiya emas, shablon satr (`"{n} ta nuqta"`) — lug‘at mijozga uzatiladi.
2. **O‘zbekcha matn aynan o‘zgarmasin** (E2E testlar o‘zbekcha standart bilan ishlaydi). Faqat tashib o‘tkazing.
3. Server komponent: `getDict()`/`getLocale()` → kerakli bo‘lim lug‘atini `X_DICT[locale]` bilan oling. Mijoz komponent: `useDict(X_DICT)`, `useLocale()`. Server → mijozga butun lug‘atni emas, kerakli qismini prop qilib uzatish ham mumkin.
4. Sana/vaqt/kg/so‘m: tilga mos `…L(…, locale)` funksiyalari. Raqamlar `tabular-nums`.
5. Foydalanuvchi kiritgan ma’lumot (izoh, manzil, sabab, do‘kon nomi) tarjima qilinmaydi.
6. Saqlanadigan erkin matn variantlari (qoldirish sababi, to‘lov usuli): ko‘rsatiladigan va saqlanadigan matn — tanlangan tildagi variant (u erkin matn sifatida saqlanadi). O‘zbekcha qiymatlar o‘zgarmaydi.
7. Server xabarlari (`ActionResult.error`, `fieldErrors`, `message`) — server tomonda tarjima qilinadi (operations-engineer, `src/i18n/messages.ts`). UI ularni o‘zgartirmasdan ko‘rsatadi.
8. `CloseCheck.label` kabi serverdan keladigan yorliqlar o‘rniga UI `key` bo‘yicha o‘z lug‘atidan oladi.
9. `metadata.title` → `generateMetadata()` bilan tilga mos.
10. Uzun ruscha so‘zlar 360 px’da sig‘sin (`break-words`, `min-w-0`), tugmalar ≥ 44 px.
